# 選擇光明，活出喜樂

一份適合青少年團契使用、全程 60 分鐘嘅聚會簡報，共 27 頁。

網站：[開啟互動簡報](https://hei08285744.github.io/light-party-presentation/)

| 檔案 | 說明 |
|---|---|
| [PowerPoint 簡報](light-party.pptx) | 文字同圖形都可以編輯，並附有每頁導師講稿。 |
| [HTML 簡報](light-party.html) | Guizang 電子雜誌風，可用瀏覽器開啟，亦可以離線播放。 |
| [網站首頁](index.html) | GitHub Pages 使用嘅互動簡報入口。 |
| [原始碼與授權](light-party-source.zip) | 包含 HTML、PowerPoint、建置來源同相關授權資料。 |

將 HTML 同 PowerPoint 放喺同一個資料夾，之後開啟 HTML，撳右下角「下載 PowerPoint」就可以下載簡報。HTML 簡報支援方向鍵翻頁、`Esc` 開啟總覽，以及 `P` 開啟講者模式。

每頁安排約 54 分鐘，留返 6 分鐘作現場彈性。第 27 頁係導師附錄，正常聚會唔需要投影。

內容已更正薩溫節日期，亦避免用單一說法概括唔同基督教傳統同所有萬聖節參加者。
